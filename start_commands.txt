To start the FastAPI Server (Foreground):
-----------------------------------------
cd real
source ../venv/bin/activate
uvicorn main:app --host 0.0.0.0 --port 8000


To start the Simulator (Foreground):
-----------------------------------------
cd real
source ../venv/bin/activate
python3 full_simulator.py


To start BOTH in the background from a single terminal:
-----------------------------------------
cd real
source ../venv/bin/activate
nohup uvicorn main:app --host 0.0.0.0 --port 8000 > server.log 2>&1 &
nohup python3 -u full_simulator.py > sim.log 2>&1 &

(You can then check their logs using `cat server.log` or `cat sim.log`)
